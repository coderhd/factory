# Factory Architecture

A Factory is an independently deployable autonomous responsibility system. It may contain multiple related domains/capabilities/subsystems when they form one coherent operational boundary.

## Factory responsibilities
Domain state, intelligence, planning, execution orchestration, domain knowledge, domain verification, workers, domain operations, evidence generation, local policy/authority and lifecycle.

## Boundary principle
A responsibility becomes a separate Factory when independent autonomy, authority, knowledge, execution, verification or lifecycle provides meaningful system-level value.

```text
Capability → Subsystem → Factory
```

A standalone Quant Factory must not require Software Factory or Root Runtime for its core operation.

Each Factory is a product in its own right: Software, Quant, Growth, Research, etc.
