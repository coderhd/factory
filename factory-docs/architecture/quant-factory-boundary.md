# Quant Factory Boundary

Quant Factory is an independent autonomous responsibility system for quantitative research, strategy evaluation and potentially controlled live execution. It is not a specialization of Software Factory.

Quant owns research workflows, data, experiment configuration, strategy lifecycle, backtesting, simulation, validation, risk evaluation, execution logic, domain knowledge, research workers and domain evidence.

Example evidence may include dataset identity, experiment configuration, strategy version, parameters, seeds, backtest results, transaction costs, validation methodology, risk measurements, market conditions, model/version provenance, decision provenance and execution receipts. This is a domain example, not a Root-mandated schema.

Root standardizes cross-Factory contracts, not Quant workflow, strategy representation, backtest engine, portfolio model, market-data architecture or research state machine.

Quant must work standalone; Root becomes valuable for ecosystem-level coordination, shared resources, cross-Factory objectives or interoperability.
