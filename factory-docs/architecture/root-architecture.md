# Root Architecture

Root provides common governance, interoperability and federation when multiple autonomous Factories coexist. It does not replace Factory-local intelligence or orchestration.

## Root owns
Identity, Factory Registry, lifecycle, qualification, ecosystem authority, ecosystem policy, shared resources, cross-Factory Operations, cross-Factory Decisions, cross-Factory Evidence, ecosystem Events, observability, audit, human control and ecosystem recovery/governance.

## Factory owns
Domain state, intelligence, planning, execution, knowledge, verification, workers, domain operations and domain evidence generation.

## Locked vocabulary
### Who owns/operates
Principal, Ecosystem, Factory, Worker.
### Why/what
Purpose, Mission, Goal, Intent, Work, Task.
### Governs execution
Capability, Authority, Policy, Resource, Decision Model, Decision.
### What happened
Result, Evaluation, Operation, Evidence, Event, State.

Knowledge is structurally a Root primitive; its ontology is domain-specific.

## Not Root primitives
Agent, Workflow/DAG, Autonomy, Risk, Trust, Recovery.

Root is an ecosystem multiplier, not a mandatory tax on standalone Factories.
