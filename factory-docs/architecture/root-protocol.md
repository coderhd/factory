# Root Protocol v1

Root Protocol is the interoperability contract between autonomous Factories and the ecosystem.

## In scope
Identity; registration/discovery; capability advertisement; Work request/acceptance; delegation; authority delegation; resource requests; Operation/Result/Evaluation/Evidence/Event exchange; lifecycle/status; errors/escalation; version negotiation.

## Out of scope
Internal Tasks, DAGs/workflows, Workers, agent conversations, domain knowledge ontology, internal verification, Factory-specific planning and execution.

Root should complement existing standards such as A2A for agent interoperability and MCP for agent-to-tool/resource interoperability rather than replace them.

Protocol semantics describe durable contracts between responsibility systems, not internal implementation details.
